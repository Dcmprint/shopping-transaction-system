# shopping-transaction-system
My python code to make a shopping transaction system

This program calculates the total cost of a shopping order based on user input for the order total and delivery option.
It includes loops to let users re-try their inputs until they enter correct answers using try and except blocks to handle invalid inputs and ensure that the user provides valid data.
On each input for float inputs theres the .strip function to allow for error and on str theres .strip and .lower to allow for cap sensitive.
